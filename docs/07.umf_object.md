# Data Preparation and unmarkedMultFrame(umf) Object Creation

## Objectives

To fit in detection histories, site covariates and observation covariates into umf object for multi-season occupancy modeling using R.

## Inputs

| File | Description |
|----------------------|--------------------------------------------------|
| output/encounter_history.csv | Encounter history matrix |
| output/dist_settlement_cov.csv | Contains distance of each grid from the settlement area |
| output/forestcover_loss.csv | Contains forest cover and forest loss data of each site for each year |
| output/ndvi_cov.csv | Contains ndvi value of each site for each year |
| output/tri_cov.csv | Contains TRI value for each site |
| output/effort_matrix.csv | Contains effort observation covariate |
| output/year_matrix.csv | Contain year observation covariate |

## Software Used

-   R

-   corrplot

## Workflow Overview

-   Import and clean the covariates data
-   Combine the dynamic covariates into one file
-   Standardize the continuous site covariates
-   Evaluate the multicollinearity among predictor variables
-   Convert encounter history into multi-season format
-   Convert observation covariates into multi-season format
-   Create site and yearly site covariates
-   Build the unmarkedMultFrame
-   Save the final object for modeling

## Detailed Workflow

### Step 1: Combine dynamic covariates into a single file

-   In our project, forest cover, forest loss, NDVI and Distance to settlement are dynamic covariates that change across years
-   Retain only the relevant columns i.e. mean values for our relevant years from the GIS derived csv files
-   Rename the variables into meaningful names
-   Merge the relevant columns in a single file using siteID column

### Step 2: Standardize the continuous covariates

-   The distance variables are converted from meters to kilometers
-   z-score standardization is applied to TRI, forest cover, forest loss, NDVI and Distance to settlement site covariates to improve numerical stability and model convergence

### Step 3: Assess Multicollinearity

-   Pearson correlation coefficients were calculated among dynamic covariates within the same year, same variables across years and static and dynamic covariates
-   Correlation matrices were visualized using corrplot()
-   Variables with \|r\| \> 0.7 were considered highly correlated and will not be used together during model building

### Step 4: Create Multi-season Encounter History Matrix

-   Split the data by primary period
-   Renamed the survey columns in year_occ format
-   Merged yearly data into the master site list
-   Converted detection histories into matrix format : sites \* survey occasions

### Step 5: Create Observation Covariate Matrices

-   Effort matrix and year matrix were also restructured into sites \* survey occasions using the step 4.
-   The observation matrices were fed into obsCovs object

### Step 6: Create yearlySiteCovariates and site covariates

-   The sites order of the dynamic and static covariates were aligned with the encounter history matrix
-   Separate matrices were created for differenct site covariates
-   Dynamic site covariates were then listed out into yearlySiteCovs object
-   Static site covariates were listed out into siteCovs

### Step 7: Construct the unmarkedMultFrame

-   The encounter history matrix, obsCovs, siteCovs and yearlySiteCovs were fed into unmarkedMultFrame function to create umf object which is a master data object that will be used for dynamic occupancy modeling in unmarked.

### Step 8: Quality check and Data export

-   The dimension of the matrices were checked
-   Ensured consistent site ordering
-   Ensured correct number of primary periods
-   Checked for missing values in covariates
-   Checked covariate alignments

# Model Building and Selection using unmarked package in R

## Objectives

To build candidate models for the four parameters and select the most suitable model to define our data.

## Inputs

| File        | Description                                            |
|-------------|--------------------------------------------------------|
| umf.RDS     | Contains eh and covariates data in desired format      |
| dyn_cov.csv | Contains dynamic covariates of all years for all sites |

## Software Used

-   R

# R Packages Used

-   unmarked
-   AICcmodavg
-   MuMIn
-   ggplot2

## Workflow Overview

-   Fit the null model for four parameters
-   Fit the detection model followed by occupancy, colonization and extinction models
-   Conduct Mackenzie-Bailey goodness of Fit test
-   Model averaged prediction for colonization model as it supported multiple models
-   Estimate prediction probability and export the result for reporting

## Detailed Workflow

### Step 1: Building Models

-   Colext() function from unmarked package is used to build the models.
-   First a null model with all parameters constant is built to get the baseline data
-   Then we first select detection model by fitting in different observation covariates inside umf object while keeping other three parameters constant.
-   After detection model, we build occupancy model while keeping the colonization and extinction covariates constatnt at 1 and detection covaraite constant with the best model selected previously
-   After selecting best occupancy model, both best detection and occupancy models are kept constant and extinction covariate is kept at 1 while selecting the best colonization model
-   Finally, keeping all the best detection, occupancy and colonization models constant, most suitable extinction model is selected
-   A final model with the best supported models for each parameters is then used for fitting the data

### Step 2: Goodness of Fit test

-   Using Mackenzie-Bailey fit test, we check whether our final model best explains our dataset

### Step 3: Model Averaged Prediction for colonization

When multiple models are supported in a parameter where no single model has dominant weightage, we do model averaged predictions. Model selection identified multiple supported colonization models with delta value less than 2. Therefore, model averaging was done to combine the predictions from all supported models while weighting each model according to its AIC support.

-   Identified all colonization models with delta AIC \<2 from the model selection results
-   Extracted AIC weights for each supported model
-   Selected the covariate of primary interest (NDVI) because it appeared consistently among supported models
-   Created a prediction gradient from the observed range of NDVI values
-   Held other relevant covariates in the supported model constant at their mean values to isolate the effect of NDVI
-   Generated colonization predictions from each supported model across the NDVI gradient
-   Extracted predicted colonization probabilities and their standard errors
-   Calculated model-averaged predictions by weighting each model prediction using its AIC weight
-   Calculated unconditional variance using Burnham and Anderson model-averaging approach, which incorporates both within-model variance and between-model variation
-   Derived 95% confidence intervals around the model-averaged predictions
-   Converted scaled NDVI values back to the original scale for interpretation and visualization
-   Produced a response curve showing the relationship between NDVI and colonization probability

### Step 4: Extinction Inference from Model Selection

Extinction model selection identified multiple competing models, but the null model had the highest support. No covariate showed strong evidence of explaining the extinction probability and model weights were distributed across different candidate models. When model averaging was attempted, singular Hessian matrices prevented reliable estimation of the model-averaged coefficients. Therefore, null model was chosen as the best supported model based directly on the model-selection results.

-   Identified all extinction models with delta AIC \<2 from the model selection results
-   Extracted AIC weights for each supported model and created prediction gradient from the covariate of primary interest while holding other covariates constant at their mean values
-   Attempted model averaging of supported models but encountered singular Hessian matrices that prevented reliable estimation of model-averaged parameters
-   Concluded that available evidence didnot support a strong effect of any measured covariate on extinction probability
-   Based extinction inference on the top-ranked null model
-   Generated extinction probability estimates using predictions from the null extinction model

### Step 5: Parameter Prediction and Probability Estimation

The ecological process governing the Common leopard occupancy dynamics were summarized by calculating predicted probabilities which will be helpful in providing biologically interpretable estimates of the four parameters.

-   Generated occupancy, detection and extinction predictions from the final selected best occupancy model, detection model and extinction model

-   Extracted predicted occupancy, detection and extinction probabilities and their associated confidence intervals

-   Calculated the mean probability of occupancy, detection and extinction across all sites

-   Used model-averaged colonization predictions derived from the supported colonization model set

-   Extracted model averaged predictions and unconditional confidence intervals

-   Calculated the mean colonization probability across the predication gradient.

-   Lower and upper 95% confidence limits were extracted from the model predictions

-   Mean confidence limits were calculated to provide an overall measure of uncertainty

-   Confidence intervals were reported alongside parameter estimates

-   A summary table containing the mean and confidence intervals of the parameter was generated

-   Individual prediction outputs were combined into a single dataset to facilitate visualization, reporting and further analysis
